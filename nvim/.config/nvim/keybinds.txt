--- Folds and diffs

Folds               n     zo                        Open/expand the fold under the cursor
                    n     zc                        Close the fold
                    n     za                        Toggle the fold
                    n     zR                        Open all folds
                    n     zM                        Close all folds

Diffs               n     ]c                        Next change
                    n     [c                        Previous change
                    n     dp                        Push across current change
                    n     do                        Pull across current change
                    n     <F2>                      Push across current change and move to next one
                    n     <F3>                      Push across current change
                    n     <F4>                      Pull across current change
                    n     <F5>                      Push all diff changes
                    n     <F6>                      Pull all diff changes

                    :     :diffupdate               Recalculate/update the diff
                    :     :diffoff                  Turn off diff mode for the current window
                    :     :diffthis                 Enable diff mode for the current window
                    :     :set diffopt?             See your diff options
